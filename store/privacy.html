OriginLint Privacy Policy

Last updated: 16 October 2026 (version 0.4.0)

What OriginLint does

OriginLint is a browser extension that checks the website in your current tab for common Cloudflare, HTTPS, security header and DNS misconfigurations. It only runs when you click its toolbar icon.

Data it reads

When you click the icon, OriginLint reads the address of the current tab, re-requests that page and up to three of its static files to read their response headers, and checks which scripts the page loaded. If you click “Run deep checks” and grant permission, it also requests that site’s http:// address and its www/root-domain counterpart to see where they redirect.

Data it sends

To check DNS records (DNSSEC, CAA, SPF, DMARC, IPv6), OriginLint sends the domain name of the scanned site to Cloudflare’s public DNS-over-HTTPS resolver at cloudflare-dns.com. Cloudflare’s handling of these queries is described in the 1.1.1.1 public resolver privacy policy. Apart from that, and the optional API mode described below, nothing leaves your browser. OriginLint has no servers of its own, no analytics and no tracking.

Optional: Cloudflare API mode

If you choose to paste a Cloudflare API token in the options page, OriginLint stores it only in this browser (chrome.storage.local, never synced) and sends it only to api.cloudflare.com, in the Authorization header of read-only requests about the zone you are scanning. OriginLint never changes a Cloudflare setting. You can remove the token at any time from the options page; removing it also revokes OriginLint’s access to api.cloudflare.com. Cloudflare’s handling of API requests is covered by Cloudflare’s privacy policy.

Data it stores

OriginLint stores the list of checks you chose to ignore, using Chrome’s storage.sync, so that list follows your Chrome profile if you use Chrome Sync. If you use API mode, it also stores your API token locally as described above. Scan results are not stored.

Sharing and sale

OriginLint does not sell, share or use data for advertising, profiling or any purpose other than producing the report you asked for.

OriginLint Gizlilik Politikası

Son güncelleme: 16 Ekim 2026 (sürüm 0.4.0)

OriginLint ne yapar

OriginLint, açık sekmedeki web sitesini yaygın Cloudflare, HTTPS, güvenlik başlığı ve DNS yapılandırma hataları için kontrol eden bir tarayıcı eklentisidir. Yalnızca araç çubuğundaki simgesine tıkladığınızda çalışır.

Okuduğu veriler

Simgeye tıkladığınızda OriginLint sekmenin adresini okur, yanıt başlıklarını görmek için sayfayı ve en fazla üç statik dosyasını yeniden ister ve sayfanın hangi betikleri yüklediğine bakar. “Derin kontrolleri çalıştır”a tıklayıp izin verirseniz, sitenin http:// adresini ve www/kök alan adı karşılığını da isteyerek nereye yönlendiklerine bakar.

Gönderdiği veriler

DNS kayıtlarını (DNSSEC, CAA, SPF, DMARC, IPv6) kontrol etmek için OriginLint, taranan sitenin alan adını Cloudflare’in herkese açık DNS-over-HTTPS çözümleyicisine (cloudflare-dns.com) gönderir. Cloudflare’in bu sorguları nasıl işlediği 1.1.1.1 çözümleyici gizlilik politikasında açıklanır. Bu ve aşağıda anlatılan isteğe bağlı API modu dışında tarayıcınızdan hiçbir veri çıkmaz. OriginLint’in kendi sunucusu, analitiği ya da izleme kodu yoktur.

İsteğe bağlı: Cloudflare API modu

Ayarlar sayfasına bir Cloudflare API token yapıştırmayı seçerseniz, OriginLint onu yalnızca bu tarayıcıda (chrome.storage.local, hiçbir zaman senkronlanmaz) saklar ve yalnızca api.cloudflare.com'a, taradığınız alan adıyla ilgili salt okunur isteklerin Authorization başlığında gönderir. OriginLint hiçbir Cloudflare ayarını değiştirmez. Token'ı ayarlar sayfasından istediğiniz zaman silebilirsiniz; silmek OriginLint'in api.cloudflare.com erişimini de kaldırır. Cloudflare'in API isteklerini nasıl işlediği Cloudflare gizlilik politikasında açıklanır.

Sakladığı veriler

OriginLint, yoksaymayı seçtiğiniz kontrollerin listesini Chrome’un storage.sync alanında saklar; Chrome Sync kullanıyorsanız bu liste profilinizle birlikte gelir. API modunu kullanıyorsanız token'ınızı da yukarıda anlatıldığı gibi yerel olarak saklar. Tarama sonuçları saklanmaz.

Paylaşım ve satış

OriginLint verileri satmaz, paylaşmaz; reklam, profilleme ya da istediğiniz raporu üretmek dışında hiçbir amaçla kullanmaz.
